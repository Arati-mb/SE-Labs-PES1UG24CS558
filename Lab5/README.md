## Project Description

This lab demonstrates static code analysis of a Python-based movie theater seat reservation system using Pylint, Bandit, and Flake8.

## Deliverables

### 1. Issues Table

File: `issues.md`

Contains the identified code issues, issue types, line numbers, descriptions, and approaches used to fix them.

### 2. Before-and-After Reports

Location: `reports/`

The following reports are included:

- `pylint_report_before.txt`
- `pylint_report_after.txt`
- `bandit_report_before.txt`
- `bandit_report_after.txt`
- `flake8_report_before.txt`
- `flake8_report_after.txt`

### 3. Source Code

File: `theater_system.py`

Contains the cleaned Python implementation of the movie theater seat reservation system.

### 4. Reflection

File: `reflection.md`

Contains reflections on static code analysis, the tools used, issues fixed, and lessons learned.

## Tools Used

- **Pylint:** Checks code quality and coding conventions.
- **Bandit:** Detects potential security issues in Python code.
- **Flake8:** Checks Python style and formatting.

## Final Results

- Pylint score: 10.00/10
- Bandit: No issues identified
- Flake8: No issues reported
