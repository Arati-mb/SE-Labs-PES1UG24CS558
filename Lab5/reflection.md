# Lab 5: Reflection on Static Code Analysis

### 1. What is static code analysis, and why is it useful?

Static code analysis examines source code without executing it. It helps identify potential bugs, security vulnerabilities, and coding-style issues early in development.

### 2. What did you learn from Pylint, Bandit, and Flake8?

Pylint helped me check code quality, Bandit helped me identify potential security issues, and Flake8 helped me check formatting and coding-style violations.

### 3. What challenges did you face while fixing the issues?

I had to understand the warnings reported by the tools and modify the code without affecting the movie theatre seat reservation program's functionality. Rerunning the tools helped me verify the fixes.

### 4. How will static code analysis help you in future projects?

Static code analysis will help me write cleaner, safer, and more maintainable code. I can use these tools regularly to detect problems early and improve software quality.
